## 🌟 معرفی پروژه

**HiddiBot Pro** یک راه‌حل همه‌کاره، قدرتمند و امن برای راه‌اندازی و مدیریت کسب‌وکار فروش کانفیگ و اشتراک‌های اینترنت آزاد است. این سیستم با اتصال به وب‌سرویس **Hiddify Manager**، تمامی مراحل ساخت کاربر، صدور لینک‌های هوشمند، تمدید خودکار، مدیریت امور مالی و تسویه‌حساب نمایندگان را به صورت ۱۰۰٪ خودکار انجام می‌دهد.

### 🛡️ معماری پایدار و بدون کرش (Zero-Crash Safe Boot)
سامانه طوری مهندسی شده است که حتی در صورت خالی بودن تمامی متغیرهای اولیه در اولین استقرار، بدون خطا و کرش بالا می‌آید و به صورت خودکار مدیر را به **ویزارد راه‌اندازی تحت وب (`/setup`)** هدایت می‌کند. همچنین هیچ دیتای فرضی یا ناخواسته‌ای به صورت پیش‌فرض در دیتابیس تزریق نمی‌شود تا هر نصب جدید کاملاً پاک و تمیز باشد.

## ✨ امکانات و قابلیت‌های برجسته

### 🌐 ۱. پنل وب مدیریت مرکزی (Super Admin Web Dashboard)
- **داشبورد زنده و مانیتورینگ آنلاین:** نمایش لحظه‌ای ترافیک مصرفی، سرورها، وضعیت درآمد و مشتریان فعال.
- **ویزارد راه‌اندازی اولیه گرافیکی (`/setup`):** امکان شروع تمیز از صفر یا بازیابی فوری با آپلود فایل بک‌آپ دیتابیس (`.json` یا `.db`).
- **پیکربندی داینامیک زیرساخت:** تنظیم توکن ربات تلگرام، کلید‌های API، مسیرهای پروکسی و دامنه‌ها بدون نیاز به دستکاری فایل متنی یا ریبوت سرور.
- **سرور مجزای تست رایگان:** امکان تفکیک کامل سرور تست هیدیفای (`HIDIFY_PANEL_URL_TEST` و `HIDIFY_API_KEY_TEST`) از سرور اصلی فروش.
- **صدور خودکار گواهی SSL:** مدیریت یکپارچه صدور سرتیفیکیت امن با Let's Encrypt و ZeroSSL با تشخیص خودکار IP عمومی سرور.
- **مدیریت پیشرفته کانال‌های اجباری:** امکان تعریف و حذف نامحدود کانال‌های عضویت اجباری به صورت داینامیک برای هر دو ربات.
- **سیستم مدیریت امور مالی، حسابداری و فاکتور رسمی:** گزارش جامع واریزی‌ها، چاپ فاکتور استاندارد با QR-Code و مدیریت کارت‌های بانکی.

### 👥 ۲. موتور قدرتمند نمایندگی و ربات‌های اختصاصی (White-Label Multi-Bot Engine)
- **ربات تلگرام مستقل برای هر نماینده:** اتصال توکن اختصاصی هر نماینده با پیام خوش‌آمدگویی، کانال اختصاصی و نام تجاری مستقل.
- **ربات اختصاصی فروش بسته‌های اعتباری نمایندگان:** ربات مجزا برای پیش‌خرید بسته‌های شارژ با شارژ بونوس هدیه، ثبت فیش، درگاه پرداخت و اعتبارسنجی کانال‌های اجباری همکاران.
- **تفکیک سطوح دسترسی مدیران:** امکان تفکیک مجوز دسترسی به ربات اصلی و ربات فروش بسته برای هر مدیر.
- **سیستم صدای زنگ واریزی:** پخش خودکار اعلان صوتی دلنشین در پنل وب هنگام ثبت فیش کارت‌به‌کارت توسط نمایندگان.

### 📱 ۳. ربات کاربری تلگرام و مینی‌اپلیکیشن وب (Telegram Mini-App)
- **مینی‌اپلیکیشن مدرن:** طراحی چشم‌نواز مشابه برترین اپلیکیشن‌های روز دنیا برای استعلام اشتراک، مشاهده ترافیک و لینک‌های کانفیگ.
- **کیف پول داخلی و سیستم رفرال هوشمند:** امکان شارژ کیف پول و دریافت پاداش دعوت از دوستان.
- **سیستم تیکتینگ و پشتیبانی دوطرفه:** پاسخگویی مستقیم مدیر و نمایندگان به تیکت‌های کاربران از طریق پنل وب و ربات تلگرام.

## 🚀 روش‌های نصب و راه‌اندازی

### ⚡ ۱. نصب خودکار تک‌خطی در سرور لینوکس (پیشنهادی)

تنها با اجرای یک دستور ساده در ترمینال سرور لینوکس (Ubuntu, Debian, CentOS, AlmaLinux, Rocky)، کل پیش‌نیازها، پایتون، پکیج‌ها و سرویس سیستمی به صورت خودکار نصب و راه‌اندازی می‌شود:

```bash
bash <(curl -sL https://raw.githubusercontent.com/MOhammaDpirouznia/TGBot/main/install.sh)
```

**امکانات اسکریپت نصب:**
1. نصب خودکار تمامی وابستگی‌ها و ایجاد محیط مجازی پایتون (`venv`).
2. پرسش از کاربر: تنظیم سریع در ترمینال یا رد کردن و تنظیم در محیط شیک گرافیکی وب (`/setup`).
3. ایجاد و استارت خودکار سرویس سیستمی `tgbot.service` جهت اجرای همیشگی پروژه در پس‌زمینه.
4. نمایش لینک پنل با آی‌پی سرور برای ورود سریع.

---

### 🚂 ۲. استقرار در سرویس ابری Railway

برای استقرار پروژه در پلتفرم ابری [Railway](https://railway.app):

1. مخزن گیت‌هاب پروژه را در حساب Railway خود **Deploy** کنید.
2. **اتصال Volume (بسیار مهم برای حفظ اطلاعات):**
   - در داشبورد سرویس، به تب **Volumes** بروید و روی **Add Volume** کلیک کنید.
   - مسیر اتصال (Mount Path) را بر روی `/data` تنظیم نمایید.
3. **متغیرهای محیطی در Railway:**
   - در تب **Variables**، متغیر زیر را اضافه فرمایید:
     ```env
     DATA_DIR=/data
     PORT=5000
     ```
4. **ورود و راه‌اندازی اولیه:**
   - پس از پایان بیلد، آدرس دامنه‌ای که ریلوی به سرویس اختصاص داده را باز کنید: `https://your-service.up.railway.app/setup`
   - در صفحه ویزارد، در صورتی که قبلاً فایل بکاپ دارید، آن را آپلود کنید تا کلیه کاربران و سوابق فوراً بازیابی شوند؛ در غیر این صورت، فرم را تکمیل کرده و از یک سیستم تمیز و صفر کیلومتر لذت ببرید!

### 🐳 ۳. استقرار با داکر (Docker & Docker-Compose)

برای اجرای کانتینری با داکر:

```bash
# ۱. کلون مخزن
git clone https://github.com/MOhammaDpirouznia/TGBot.git /opt/tgbot
cd /opt/tgbot

# ۲. اجرای کانتینر
docker-compose up -d
```

سپس به آدرس `http://SERVER_IP:5000/setup` مراجعه کنید.

## ⚙️ جدول متغیرهای پیکربندی

کلیه متغیرهای زیر را می‌توانید به دو روش تنظیم کنید:
۱. از طریق فایل `.env` یا بخش Variables در سرویس‌های ابری
۲. از طریق **پنل وب مدیریت > تنظیمات زیرساخت** (کاملاً داینامیک و بدون نیاز به ری‌استارت)

| متغیر محیطی | معادل در دیتابیس پنل | توضیح و کاربرد |
| :--- | :--- | :--- |
| `BOT_TOKEN` | `bot_token` | توکن ربات اصلی تلگرام از BotFather |
| `ADMIN_ID` | `admin_id` | شناسه عددی تلگرام مدیر ارشد جهت دریافت اعلان‌ها |
| `HIDIFY_PANEL_URL` | `hidify_panel_url` | آدرس کامل دامنه پنل هیدیفای اصلی |
| `HIDIFY_API_KEY` | `hidify_api_key` | کلید دسترسی API وب‌سرویس هیدیفای |
| `HIDIFY_PROXY_PATH` | `hidify_proxy_path` | مسیر پروکسی مدیریت هیدیفای (Secret Path) |
| `USER_PROXY_PATH` | `user_proxy_path` | مسیر پروکسی کاربران جهت صدور لینک‌های اشتراک |
| `HIDIFY_PANEL_URL_TEST` | `hidify_panel_url_test` | آدرس سرور مجزای تست رایگان (اختیاری) |
| `HIDIFY_API_KEY_TEST` | `hidify_api_key_test` | کلید API سرور تست هیدیفای (اختیاری) |
| `HIDIFY_PROXY_PATH_TEST`| `hidify_proxy_path_test`| مسیر پروکسی ادمین سرور تست (اختیاری) |
| `USER_PROXY_PATH_TEST`  | `user_proxy_path_test`  | مسیر پروکسی کاربران سرور تست (اختیاری) |
| `DATA_DIR` | - | مسیر ذخیره‌سازی داده‌های پایدار (دیتابیس، بکاپ‌ها، رسیدها و SSL) |
| `DASHBOARD_SECRET` | `dashboard_secret` | کلید رمزنگاری جلسات لاگین در Flask |
| `PORT` | - | پورت اجرای وب‌سرور پنل مدیریت (پیش‌فرض: 5000) |
| `CUSTOM_DOMAIN` | `custom_domain` | دامنه اختصاصی متصل به پنل با پشتیبانی از SSL |

## 🛠️ دستورات پرکاربرد مدیریت سرویس در لینوکس

در صورتی که پروژه را با اسکریپت خودکار یا `systemd` نصب کرده‌اید:

```bash
# بررسی وضعیت اجرای سرویس
systemctl status tgbot

# ری‌استارت سرویس پس از بروزرسانی
systemctl restart tgbot

# مشاهده لاگ‌های زنده سیستم
journalctl -u tgbot -f

# متوقف‌سازی سرویس
systemctl stop tgbot
```

## 🔒 امنیت، بکاپ و حفاظت از داده‌ها

- **تضمین سلامت دیتای لایو:** این پروژه طوری طراحی شده است که اطلاعات موجود در دیتابیس فعلی شما هرگز با آپدیت‌های جدید دچار اختلال نمی‌شود.
- **بکاپ‌گیری خودکار و دستی:** از طریق تب **سیستم و بکاپ** در پنل مدیریت، می‌توانید با یک کلیک فایل جامع پشتیبان (`.json` یا `.db`) دریافت فرمایید.
- **پایداری کامل:** با اختصاص `DATA_DIR=/data` در ریلوی و داکر، هیچ بیلد مجددی اطلاعات مشتریان را حذف نخواهد کرد.
