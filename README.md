# 🤖 ربات تلگرام مدیریت VPN

ربات تلگرام برای مدیریت اشتراک VPN با اتصال به پنل Hidify

## ✨ امکانات

- 🛒 خرید اشتراک جدید
- 🔄 تمدید اشتراک
- 📊 مشاهده وضعیت اشتراک (حجم مصرفی، تاریخ انقضا)
- 🔗 دریافت لینک اتصال
- 📖 راهنما

## 📋 پلن‌های اشتراک

| پلن | حجم | مدت | قیمت |
|-----|------|------|------|

| استاندارد | 60 گیگ | 30 روز | 80,000 تومان |

## 🚀 نصب و راه‌اندازی

### 1. نصب Python

مطمئن شوید Python 3.8 یا بالاتر نصب شده است.

### 2. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 3. تنظیم فایل .env

فایل `.env` را ویرایش کنید و اطلاعات خود را وارد کنید:

```
BOT_TOKEN=توکن_ربات_تلگرام
HIDIFY_PANEL_URL=آدرس_پنل
HIDIFY_API_KEY=کلید_API
```

### 4. اجرای ربات

```bash
python bot.py
```

## 🛠️ ساختار کد

### HidifyClient
کلاس اصلی برای اتصال به API پنل Hidify:
- `get_users()` - دریافت لیست کاربران
- `get_user(username)` - دریافت اطلاعات کاربر
- `create_user(username, data_limit, expire)` - ساخت کاربر جدید
- `update_user(username, data_limit, expire)` - بروزرسانی کاربر
- `delete_user(username)` - حذف کاربر
- `get_user_subscription(username)` - دریافت لینک اشتراک

### هندلرهای ربات
- `start()` - شروع ربات و نمایش منو
- `show_plans()` - نمایش پلن‌های اشتراک
- `plan_selected()` - انتخاب پلن
- `confirm_purchase()` - تایید خرید
- `show_status()` - نمایش وضعیت اشتراک
- `get_link()` - دریافت لینک اتصال
- `renew_subscription()` - تمدید اشتراک

## ⚠️ نکات امنیتی

1. فایل `.env` را هرگز در مخزن Git قرار ندهید
2. توکن ربات و API Key را محرمانه نگه دارید
3. از HTTPS برای اتصال به پنل استفاده کنید
4. به‌صورت دوره‌ای کلیدهای API را تغییر دهید
