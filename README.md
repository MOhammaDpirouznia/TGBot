# 🚀 سامانه جامع و هوشمند مدیریت، فروش و نمایندگی VPN (HiddiBot Pro)

سامانه یکپارچه و پیشرفته مدیریت فروش، اتوماسیون اشتراک‌های VPN، پنل نمایندگی وایت‌لیبل (Multi-Bot & Custom Domain)، ربات تلگرام، مینی‌اپلیکیشن وب (Telegram Mini-App) و اتصال دوطرفه به سرورهای **Hiddify Manager / Xray / Sing-box**.

---

## ✨ امکانات و قابلیت‌های برجسته سامانه

### 🌐 ۱. پنل وب مدیریت مرکزی (Super Admin Dashboard)
- **داشبورد زنده و مانیتورینگ آنلاین:** پایش ثانیه‌ای مشتریان متصل، وضعیت سلامت سرور هیدیفای (Latency & Healthcheck) و گزارش‌های ترافیک.
- **کنترل دسترسی نقش‌محور (RBAC):** پشتیبانی از نقش‌های `super_admin` (مدیر ارشد)، `partner` (شریک با سهم سود و ثبت بدهی)، `finance` (مدیر مالی و فیش‌ها)، `support` (پشتیبانی و تیکت‌ها) و `viewer` (ناظر فقط‌خواندنی).
- **مدیریت کامل اشتراک‌ها:** تمدید، تغییر وضعیت، افزایش حجم ترافیک (Top-up)، تغییر سرور، حذف و استرداد وجه خودکار.
- **فاکتور دیجیتال رسمی با QR کد:** صدور و چاپ فاکتور رسمی شیک با قابلیت استعلام و اسکن بارکد اشتراک.
- **حسابداری پیشرفته و مدیریت بدهی‌ها:** ثبت تسویه اقساطی/پاره‌وقت بدهی شرکا و ارسال خودکار اعلان یادآوری به تلگرام بدهکار.
- **مدیریت کارت‌های بانکی و کدهای تخفیف:** تعیین سقف تراکنش روزانه، کدهای تخفیف درصدی و ریالی با سقف استفاده.
- **پیام همگانی و لاگ‌های امنیتی:** ارسال پیام به کلیه کاربران ربات و ثبت لاگ کلیه عملیات مدیران.

### 👥 ۲. پنل اختصاصی و مستقل همکاران و نمایندگان (White-Label Reseller Engine)
- **ربات اختصاصی تلگرام (Multi-Bot Architecture):** امکان اتصال توکن ربات تلگرام اختصاصی برای هر نماینده با پیام خوش‌آمدگویی، دکمه‌های راهنمای اتصال و کانال مجزا.
- **مدیریت پلن‌ها و قیمت‌گذاری اختصاصی (Custom Plans):** امکان تعریف نام‌های نمایشی و قیمت‌های دلخواه توسط هر نماینده با حفظ حجم و مدت پلن از مدیریت مرکزی و کسر هزینه عمده طبق درصد تخفیف.
- **بسته‌های شارژ عمده با بونوس ویژه (Volume Bundles):** پیش‌خرید اعتباری با شارژ هدیه تا ۱۵٪، پشتیبانی از درگاه پرداخت آنلاین شاپرک و ثبت فیش کارت‌به‌کارت.
- **اعلان صوتی هوشمند رسیدهای نماینده:** تولید صدای زنگ اختصاصی با Web Audio API برای تشخیص سریع فیش‌های واریزی نمایندگان.
- **مرتب‌سازی هوشمند جداول (Column Sorting):** سورت دوطرفه صعودی/نزولی بر اساس شماره سفارش، کاربر، پلن، مبلغ، روش پرداخت، وضعیت و تاریخ ثبت.
- **هویت بصری و دامنه اختصاصی (Custom Domain & Branding):** اتصال دامنه اختصاصی به پنل نماینده، آپلود لوگو، فاویکون و تغییر رنگ‌بندی سازمانی.
- **مدیریت تیم و زیرمدیران (Sub-Admins):** امکان تعریف اپراتور و کارمند پشتیبانی برای هر نماینده با تفکیک وظایف.
- **فروشگاه و درگاه کارت‌به‌کارت اختصاصی:** کارت‌های بانکی مقصد و کدهای تخفیف مجزا برای هر نماینده.

### 📱 ۳. ربات تلگرام و مینی‌اپلیکیشن وب (Telegram Mini-App)
- **خرید، تمدید و استعلام آنی:** مشاهده ترافیک مصرفی، تاریخ انقضا و وضعیت کانفیگ‌ها با یک لمس.
- **سیستم پرداخت جامع و دکمه‌های کپی هوشمند:** پرداخت با کیف پول، درگاه آنلاین و کارت‌به‌کارت با دکمه‌های کپی تک‌کلیک شماره کارت و مبلغ.
- **آواتارهای سه‌بعدی و هوشمند:** تولید خودکار آواتارهای مدرن محلی بدون افت سرعت.
- **سیستم رسید موقت و اتصال آنی (Grace Period):** فعال‌سازی ۲۴ ساعته کانفیگ برای مشتری بلافاصله پس از ثبت فیش تا زمان تایید مالی.
- **سیستم وفاداری و رفرال چندسطحی (Cashback & Referral):** واریز پورسانت خودکار به کیف پول معرف در زمان خرید زیرمجموعه.

## 🛠️ پیش‌نیازها

- **سیستم‌عامل:** لینوکس (Ubuntu 20.04/22.04/24.04 recommended) یا ویندوز
- **پایتون:** Python 3.10 یا بالاتر
- **دیتابیس:** SQLite 3 (داخلی بدون نیاز به نصب سرویس اضافی)
- **سرور هیدیفای:** آدرس پنل و توکن API از Hiddify Manager

## ⚡ راهنمای سریع راه‌اندازی در ۵ دقیقه

### ۱. کلون یا کپی پروژه و ساخت محیط مجازی:
```bash
cd /opt/HiddiBot
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### ۲. پیکربندی فایل متغیرهای محیطی (`.env`):
یک کپی از فایل `.env.example` ایجاد کرده و مقادیر مورد نیاز را وارد کنید:
```bash
cp .env.example .env
nano .env
```

نمونه محتوای اصلی `.env`:
```env
# ─── تنظیمات ربات تلگرام ───
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=123456789

# ─── تنظیمات سرور هیدیفای (Hiddify Manager) ───
HIDIFY_PANEL_URL=https://panel.yourdomain.com/secret_path/
HIDIFY_API_KEY=your_hiddify_admin_api_key

# ─── تنظیمات پنل وب و داشبورد ───
SECRET_KEY=your_super_secret_flask_key_random_string
ADMIN_USERNAME=admin
ADMIN_PASSWORD=strong_admin_password
PORT=5000
DEBUG=False
```

### ۳. اجرای سامانه:
```bash
# اجرای همزمان ربات و داشبورد مدیریت:
python run.py
```
سپس مرورگر خود را باز کرده و به آدرس `http://YOUR_SERVER_IP:5000` مراجعه فرمایید.

## 📂 ساختار فایل‌های پروژه

```
├── bot.py                  # موتور اصلی ربات تلگرام و هندلرهای کاربران
├── dashboard.py            # وب‌سرور فلسک، روت‌های پنل مدیریت و نمایندگی
├── database.py             # لایه ارتباط با دیتابیس SQLite و منطق داده‌ها
├── hidify_api.py           # کلاینت ارتباط بلادرنگ با API هیدیفای
├── multibot_manager.py     # موتور چندرباته مستقل برای نمایندگان
├── utils.py                # توابع کمکی، تولید QR، تاریخ شمسی و لینک‌ها
├── session_analyzer.py     # آنالایزر نشست‌ها و اپراتورهای مخابراتی
├── templates/              # قالب‌های مدرن ریسپانسیو Bootstrap 5
├── static/                 # فایل‌های استاتیک، CSS و JS
├── data/                   # دیتابیس SQLite و بکاپ‌های محلی
├── cache_avatars/          # کش آواتارها و لوگوهای آپلود شده
├── Dockerfile              # داکر فایل استقرار کانتینری
├── docker-compose.yml      # کانفیگ اجرای آسان با Docker Compose
└── requirements.txt        # پکیج‌های پیش‌نیاز پایتون
```

## 🔒 امنیت و نگهداری

1. فایل `.env` حاوی اطلاعات محرمانه است؛ آن را هرگز در مخازن عمومی گیت قرار ندهید.
2. همیشه از پروتکل HTTPS (SSL) در پنل مدیریت و ارتباطات وب‌هوک تلگرام استفاده کنید.
3. دیتابیس در فایل `data/bot.db` ذخیره می‌شود؛ پشتیبان‌گیری منظم با دکمه «بکاپ دیتابیس» در داشبورد یا دستورات `MIGRATION_GUIDE.md` توصیه می‌شود.
