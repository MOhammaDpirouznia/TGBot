۱. تریگر (Trigger): پیامک دریافتی (SMS Received) از سرشماره‌های بانکی
۲. اکشن (Action): ارسال درخواست HTTP Request با متد POST
۳. آدرس (URL): آدرس وب‌هوک اختصاصی بالا
۴. نوع محتوا (Content Type): application/json
۵. متن بدنه (Request Body):
{
  "sender": "[sms_number]",
  "message": "[sms_message]"
}
📌 حتماً از [sms_message] استفاده کنید (نه [sms_body])
پیکربندی در اپلیکیشن SMS Forwarder
۱. نوع ارسال (Sender Type): Webhook / HTTP Post
۲. آدرس مقصد (Target URL): آدرس وب‌هوک اختصاصی بالا
۳. هدرها (Headers): Content-Type: application/json
۴. بدنه درخواست (Request Body):
{
  "sender": "[from]",
  "message": "[content]"
}
📌 در SMS Forwarder از [content] استفاده فرمایید.
